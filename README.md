# E-Commerce Sales & Customer Analytics Using Microsoft SQL Server (MSSQL)

## Project Overview

This project demonstrates the use of Microsoft SQL Server (MSSQL) to analyze e-commerce transactional data and generate business insights through SQL queries. The project focuses on customer analytics, sales performance, product analysis, and inventory reporting by solving real-world business requirements.

## Problem Statement

An e-commerce company generates large volumes of transactional data that require analysis to monitor sales performance, customer purchasing behavior, product demand, and inventory levels. This project transforms raw transactional data into meaningful business insights using SQL.
